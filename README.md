# CSE3120-Contest-2-Project

## Escape the CPU 2.0
### A refined and improved version of Escape the CPU from Contest 1
### By Madison Sujanani and Thomas Do

## Description
Escape the CPU 2.0 takes the typing game concept and uses it as one of the ways to escape the CPU. Along with typing increasingly strange phrases correctly, players must complete other puzzles within a set time to ESCAPE THE CPU!
